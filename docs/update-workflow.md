# Update workflow concept

1. New information is linked to an explicit source ID.
2. The system checks whether the information already exists.
3. A proposal is created without changing accepted content.
4. An owner reviews exact quotations, labels and any conflict.
5. After approval, the new material is appended as a numbered update.
6. Integrity checks are rerun and the change is versioned.

The public site demonstrates the concept only. The actual owner-approved workflow runs in the private local application.
