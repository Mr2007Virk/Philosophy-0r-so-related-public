# Public release checklist

Before turning on GitHub Pages, verify:

- [ ] Only this public showcase is in the public repository.
- [ ] No SQLite database, owner PIN, private source snapshots, user/AI conversation exports, or personal philosophical reflections are present.
- [ ] The demo records are clearly labelled fictional.
- [ ] The project credits are accurate.
- [ ] A licence decision has been made (or the repository is explicitly published without granting a reuse licence).
- [ ] The integrity page returns PASS.
- [ ] The public page is read-only and does not claim to be the private live archive.
